# 🧠 MindHub 2.0 - Gestão Pessoal & Produtividade

O **MindHub** é uma aplicação web completa, moderna e responsiva para gestão pessoal, financeira e produtividade diária. Desenvolvido com arquitetura modular limpa em JavaScript (ES Modules) e estilizado com Tailwind CSS.

## 🚀 Funcionalidades

- **Dashboard Integrado:** Visão geral de tarefas, finanças, hábitos e metas.
- **Tarefas & Kanban:** Gerenciamento visual com suporte a prioridades e filtros.
- **Gestão Financeira:** Controle de receitas, despesas e gráficos analíticos.
- **Rastreador de Hábitos:** Matriz semanal para manter consistência.
- **Notas & Ideias:** Bloco de notas flexível com sistema de tags.
- **Timer Pomodoro:** Timer configurável com animação SVG e alertas sonoros.
- **Lista de Desejos & Metas:** Acompanhamento financeiro de metas com feedback visual.
- **Persistência Local:** Salvamento automático no `localStorage` do navegador.

## 🛠️ Tecnologias Utilizadas

- HTML5 / CSS3 (Glassmorphism UI)
- [Tailwind CSS](https://tailwindcss.com/)
- JavaScript ES6+ (ES Modules)
- [Chart.js](https://www.chartjs.org/)
- [FontAwesome](https://fontawesome.com/)
- [Canvas Confetti](https://www.npmjs.com/package/canvas-confetti)

## 📦 Como Executar

Por utilizar **ES Modules** (`import`/`export`), o navegador exige que o projeto seja servido via protocolo `http://` ou `https://` (e não aberto direto como arquivo local `file://`).

1. Clone o repositório ou baixe os arquivos.
2. Abra a pasta no **VS Code**.
3. Inicie o servidor local usando a extensão **Live Server** (ou via Node.js / Python `python -m http.server`).
4. Acesse no navegador: `http://localhost:5500`
